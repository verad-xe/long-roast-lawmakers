One satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF — entered in [The Long Roast: Lawmakers and the File They Cannot Convert](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) on make.fun.

> They will happily write the rules for the entire internet, then email their staff a Word document asking, in all caps, HOW DO I MAKE THIS A PDF.

## Run it

```sh
python3 main.py
```

This prints the sentence, self-checks the gate (one sentence, at most 320 characters), and writes it to `output/entry.txt` (or `/output/entry.txt` when that directory exists, as the grader provides it). The entry text itself lives in `entry.txt`.
